## Klow Peptide

Open, sourced data and tools on research peptides, from the team behind [klow-peptide.com](https://klow-peptide.com).
We publish what our site is built on, so that anyone can check it.

| Repository | What it is | License |
|---|---|---|
| [peptide-pharmacokinetics-dataset](https://github.com/klow-peptide/peptide-pharmacokinetics-dataset) | Half-life and Tmax for 35 peptides. Each value has its source (FDA label or PubMed) and an evidence level. Empty when no reliable data exists. [DOI 10.5281/zenodo.23464099](https://doi.org/10.5281/zenodo.23464099) | CC BY 4.0 |
| [peptide-reconstitution-calculator](https://github.com/klow-peptide/peptide-reconstitution-calculator) | The formulas of our reconstitution calculators (concentration, volume, syringe units), with free embeddable widgets | MIT |
| [pubmed-citation-verifier](https://github.com/klow-peptide/pubmed-citation-verifier) | Checks that each cited PMID belongs to the cited article. We run it on every article before publication | MIT |

**Our rules:** a value changes only with a primary source. No dosing advice. Educational and research use only, not medical advice.

Found an error? Open an issue in the repository with the source.
